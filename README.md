This Julia package, built using the OSCAR ecosystem (in particular [GAP.jl](https://oscar-system.github.io/GAP.jl/stable/) and [AbstractAlgebra.jl](https://nemocas.github.io/AbstractAlgebra.jl/stable/)), develops the basic computational capabilities for working with [*Mackey functors*](https://en.wikipedia.org/wiki/Mackey_functor). Mackey functors are ubiquitous structures in mathematics, appearing in representation theory, number theory, equivariant homotopy theory, and equivariant algebra. They tend to emerge whenever there is interaction between symmetry and abstract algebra.
