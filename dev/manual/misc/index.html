MackeyFunctors.HomModule — Type
HomModule(M::FPModule, N::FPModule)

Represent $Hom_R(M, N)$ as a finitely presented module over the common base ring of M and N.

The underlying module is available as underlying_module. Elements of that module can be converted to module homomorphisms with as_homomorphism, and module homomorphisms can be converted back with as_hom_module_element.

MackeyFunctors.double_coset_representative_data — Function
double_coset_representative_data(ctx, j, h, k)
double_coset_representative_data(ctx, J, H, K)

Return representatives for J \ H / K, where J < H and K < H are cover relations in ctx.

Each representative is returned as (word, intersection_index), where intersection_index points to J^x intersected with K in ctx.subgroups for the represented group element x.

MackeyFunctors.submodules_matrix — Function
MackeyFunctors.submodules_matrix([f], (M1, f1), (M2, f2))

Let f1 and f2 be morphisms with domains M1 and M2, where f2 is assumed to be injective. Also, let f be a morphism from codomain(M1) to codomain(M2). This function returns a morphism g from M1 to M2 such that f2(g(m)) equals f(f1(m)) for all m in M1.

If f is not given, it is assumed to be the identity map.
