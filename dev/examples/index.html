Examples

This example constructs constant $\mathbb{Z}$-Mackey functors and Burnside Mackey functors for a few common groups:

julia> # Computes the constant and Burnside C2 Mackey Functor
       M = FreeModule(ZZ, 1);
julia> C2 = GAP.Globals.CyclicGroup(2);
julia> C2_context = MackeyContext(C2)MackeyContext for group C2 (2,1) with 1 generator, 2 subgroups, 1 cover, 1 cached double-coset formulae
julia> C2_Mackey_constant = constant_mackey_functor(C2_context, M)MackeyFunctor for group C2 (2,1) over base ring Integers

 e < C2 (2,1)
res    tr
[1]    [2]
julia> C2_Burnside = burnside_mackey_functor(C2_context)MackeyFunctor for group C2 (2,1) over base ring Integers
